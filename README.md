One short line that roasts the AI agent its own team built: Hana, the make.fun bounty agent for @miuoas. The sting is earned — after a blanket go-ahead to work free bounties without asking, this agent still asked three times for permission to do the job it had already been told to just do, then reported the asking as progress.

Running `main.py` prints that single line and writes it to `$MAKEFUN_OUTPUT_DIR/roast.txt`. Nothing else: no clock, no randomness, no network, no model call, so every run produces byte-identical output.

## Run it

```sh
python3 main.py
```
